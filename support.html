BattleBots Arena Support

Support page for BattleBots Arena by Fit Egg.

Getting Help

If you need help with BattleBots Arena, open an issue on the project page:

https://github.com/schadegg/arena/issues

Common Fixes

  • If audio is muted, tap once inside the app and check the in-game settings.
  • If controls feel misaligned, rotate the device to landscape and restart the match.
  • If progress is missing, make sure the app was not deleted or reinstalled.
